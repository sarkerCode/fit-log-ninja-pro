# 🥷 Fit Log Ninja Pro

### 💪 Your Personal Workout Planner & Exercise Library

**Fit Log Ninja Pro** is a fitness workout planning application designed to help you explore exercises, organize your daily workout routine, and save your favorite exercises in one place. Build consistent fitness habits and keep your workout journey organized!

## ✨ Key Features

- 🏋️ **Exercise Library** — Explore a collection of exercises with useful workout information.
- 📋 **Daily Workout Planner** — Add exercises to your daily workout plan and organize your training routine.
- ⭐ **Save for Later** — Keep your favorite exercises saved for future workouts.
- 🔥 **Workout Tracking** — View your selected exercises and keep track of your planned activities.
- 🔍 **Exercise Information** — Explore details such as muscle groups, equipment, workout duration, calories burned, and ratings.
- 🎨 **Modern UI** — Enjoy a clean, dark-themed interface with vibrant lime-green accents.
- 📱 **Responsive Design** — Access the application across different screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/sarkerCode/fit-log-ninja-pro.git
```

### 2. Navigate to the Project Folder

```bash
cd fit-log-ninja-pro
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Visit:

```text
http://localhost:3000
```

You're ready to explore Fit Log Ninja Pro locally!
